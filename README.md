# Data Cleaning Project with SQL — Layoffs Dataset

## 📌 Project Overview

This project focuses on cleaning and preparing a layoffs dataset using SQL. The goal is to improve data quality, maintain consistency, and make the dataset suitable for further analysis.

The project demonstrates essential data cleaning techniques using SQL queries, including removing duplicates, standardizing data, handling NULL and blank values, and removing unnecessary rows and columns.

## 🎯 Project Objectives

The main objectives of this project are to:

- Remove duplicate records from the dataset.
- Standardize data and correct inconsistencies.
- Identify and handle NULL and blank values.
- Remove unnecessary rows and columns to improve data quality.

## 🛠️ Tools Used

- **SQL** — Data cleaning and transformation.
- **MySQL** — Database management and query execution.
- **GitHub** — Project documentation and version control.

## 🧹 Data Cleaning Process

### 1. Remove Duplicates
Identified and removed duplicate records to ensure that each relevant record appears only once in the dataset.

### 2. Standardize the Data
Standardized inconsistent data formats and values to improve uniformity across the dataset. This included correcting inconsistencies in text fields and ensuring data was properly formatted.

### 3. Handle NULL and Blank Values
Identified NULL and blank values across relevant columns. Evaluated missing data and handled it where appropriate to improve data completeness without introducing misleading information.

### 4. Remove Unnecessary Rows and Columns
Removed irrelevant rows and columns that were not needed for the intended analysis, resulting in a cleaner and more manageable dataset.

## 📊 Key Skills Demonstrated

- Data cleaning and preprocessing

- Data standardization

## ✅ Project Outcome

The project demonstrates how SQL can be used to transform a raw layoffs dataset into a cleaner, more consistent, and analysis-ready dataset.

It also highlights the importance of data quality and accuracy before performing exploratory data analysis or generating business insights.
